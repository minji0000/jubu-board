## 🚀 Project Migration Notice (2026-01 ~ 2026-03)

본 프로젝트는 더 나은 성능과 개발 환경 최적화를 위해 **Java 17** 및 **Gradle** 환경으로 전환될 예정입니다. 

### ✅ 현재까지 구현된 기능
* 프로젝트 초기 설계 및 핵심 게시판 CRUD 로직 구현
* Spring Web MVC + JPA 기반 안정화 단계 완료
* **Global Exception Handling**을 통한 공통 예외 처리 로직 구현
* **Lombok** 적용을 통한 도메인 모델 최적화

### 🔄 마이그레이션 사유
* **Java 8 -> 17**: 최신 LTS 버전의 기능 활용 및 성능 향상
* **Maven -> Gradle**: 빌드 속도 개선 및 유연한 의존성 관리
* **Redis 적용 준비**: 대규모 트래픽 처리를 위한 캐싱 전략(조회수 최적화 등) 도입 예정

🌈 새로운 프로젝트 환경은 아래 레포지토리(혹은 새로운 브랜치/폴더)에서 계속 이어집니다. !
